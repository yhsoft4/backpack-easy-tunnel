## مفاهیم

| اصطلاح | معنی |
|---|---|
| **ایران / ورودی** (`iran`) | سروری که کاربران به آن وصل می‌شوند. *گوش می‌دهد*: پورت تانل + پورت‌های فوروارد. |
| **خارج / خروجی** (`kharej`) | سرور خارج که سرویس اصلی روی آن است. *به ایران وصل می‌شود*. |
| **پورت تانل** | پورتی روی سرور ایران که سرور خارج به آن وصل می‌شود (پیش‌فرض `7001`). خودِ تانل از آن رد می‌شود و کاربران هرگز از آن استفاده نمی‌کنند. |
| **پورت‌های فوروارد** | پورت‌هایی روی سرور ایران که کاربران به آن‌ها وصل می‌شوند. هر کدام به یک پورت سمت خارج نگاشت می‌شود. |
| **توکن** | رمز مشترک. هر دو طرف باید دقیقاً یکی داشته باشند. |

همیشه **اول سمت ایران** را راه بیندازید (توکن را می‌سازد)، بعد سمت خارج.

## راه‌اندازی گام‌به‌گام

### سرور ایران

```bash
sudo ./bpt.sh install iran \
  --port 7001 \
  --ports "80,443,2053=127.0.0.1:2096,10000-10009" \
  --udp yes
```

به ترتیب این کارها را می‌کند:

1. نسخه‌ی BackPack مناسب پردازنده‌تان را دانلود و `SHA256SUMS` را بررسی می‌کند.
2. فایل `/etc/backpack/bpt.toml` (با دسترسی `600`) را با یک توکن تصادفی می‌سازد.
3. سرویس systemd به نام `backpack-bpt.service` را می‌سازد و اجرا می‌کند.
4. پورت تانل و پورت‌های فوروارد را در **ufw** یا **firewalld** (اگر فعال باشد) باز می‌کند. اگر فعال نباشد می‌گوید کدام پورت‌ها را باز کنید (فایروال ابری یا Security Group ارائه‌دهنده را **دست نمی‌زند**؛ از پنل ارائه‌دهنده باز کنید).
5. دستور دقیق سرور خارج را چاپ می‌کند.

### سرور خارج

```bash
sudo ./bpt.sh install kharej --server IP_ایران:7001 --token <توکن>
```

گزینه: `--pool 8` (تعداد اتصال‌های آماده؛ برای کاربران هم‌زمان زیاد بیشتر کنید).

### بررسی

```bash
sudo ./bpt.sh status         # روی هر دو سرور: دنبال "control channel established" بگردید
sudo ./bpt.sh logs           # لاگ زنده
```

## تغییر پورت‌ها و آی‌پی‌ها

**پورت‌های فوروارد** (سرور ایران):

```bash
sudo ./bpt.sh ports                                  # نمایش
sudo ./bpt.sh ports --set "80,443=127.0.0.1:2096"    # جایگزینی کل فهرست
```

فهرست بازنویسی می‌شود، پورت‌های فایروال باز می‌شوند و تانل ری‌استارت می‌شود (اتصال‌های فعلی لحظه‌ای قطع می‌شوند).

**آی‌پی ایران عوض شد** (مثلاً آی‌پی قبلی مسدود شد و آی‌پی جدید گرفتید) — روی سرور **خارج**:

```bash
sudo ./bpt.sh set-server IP_جدید          # پورت فعلی حفظ می‌شود
sudo ./bpt.sh set-server IP_جدید:7001     # یا هر دو
```

روی سمت ایران چیزی لازم نیست عوض شود، چون روی همه‌ی آدرس‌ها گوش می‌دهد. اگر روی سرور خارج **fail2ban** دارید، آی‌پی جدید را هم سفیدلیست کنید ([امنیت](#امنیت)).

**پورت تانل عوض شد:**

1. ایران: `sudo ./bpt.sh install iran --force --port پورت_جدید --ports "<همان فهرست>" --token <همان توکن>`
2. خارج: `sudo ./bpt.sh set-server IP_ایران:پورت_جدید`

**آی‌پی سرور خارج عوض شد:** کاری لازم نیست — خودش به ایران وصل می‌شود، پس آی‌پی خودش مهم نیست.

**کاربران کجا وصل می‌شوند:** به پورت‌های فوروارد روی آی‌پی ایران. اگر برای آن آی‌پی دامنه گذاشته‌اید، فقط رکورد DNS عوض می‌شود.

## چند تانل روی یک سرور

از `--name` استفاده کنید. هر تانل تنظیمات و سرویس خودش را دارد (`/etc/backpack/NAME.toml` و `backpack-NAME.service`). پورت تانل و پورت‌های فوروارد تانل‌های مختلف نباید با هم تداخل داشته باشند.

```bash
sudo ./bpt.sh --name vpn1 install iran --port 7001 --ports "443"
sudo ./bpt.sh --name web  install iran --port 7002 --ports "80=127.0.0.1:8080"
sudo ./bpt.sh list
sudo ./bpt.sh --name web status
```

می‌توانید به سرور خارج دیگری هم فوروارد کنید، مثلاً سروری که سرور خارج اول به آن دسترسی دارد: `--ports "443=203.0.113.10:443"`.

## نصب آفلاین

اگر سرور به GitHub دسترسی ندارد (در ایران رایج است):

1. روی دستگاهی که دسترسی دارد، از [صفحه‌ی نسخه‌های BackPack](https://github.com/AminMGMT/BackPack/releases) فایل مناسب پردازنده را دانلود کنید، مثلاً `backpack_linux_amd64.tar.gz` (با `uname -m` بررسی کنید: `x86_64` ← amd64 و `aarch64` ← arm64).
2. آن را به همراه `bpt.sh` با `scp` به سرور ببرید.
3. اجرا کنید:

```bash
BPT_TARBALL=./backpack_linux_amd64.tar.gz sudo -E ./bpt.sh install iran
# یا اگر باینری استخراج‌شده را دارید:
BPT_BINARY=./backpack sudo -E ./bpt.sh install iran
```

حالت آفلاین دانلود checksum را رد می‌کند. فایل را خودتان با `SHA256SUMS` صفحه‌ی نسخه مقایسه کنید: `sha256sum backpack_linux_amd64.tar.gz`.

می‌توانید آینه هم بگذارید: `BP_BASE_URL=https://mirror.example/releases ./bpt.sh install iran`.

## افزایش سرعت

مسیرهای طولانی بین‌المللی به الگوریتم کنترل ازدحام TCP و اندازه‌ی بافرها حساس‌اند. روی **هر دو** سرور:

```bash
sudo ./bpt.sh tune
```

این دستور **BBR** را با `fq` و بافرهای بزرگ‌تر TCP فعال می‌کند (`/etc/sysctl.d/99-bpt-tune.conf`). بررسی:

```bash
sysctl net.ipv4.tcp_congestion_control   # bbr
```

اگر باز هم کند بود، [عیب‌یابی](troubleshooting.fa.md#کندی-و-لگ) را ببینید.

## امنیت

* **توکن:** پیش‌فرض ۶۴ نویسه‌ی هگز تصادفی. هر کس توکن را داشته باشد و به پورت تانل برسد می‌تواند به تانل شما وصل شود. فایل تنظیمات `chmod 600` است. توکن را جای عمومی نگذارید.
* **پورت تانل:** فقط سرور خارج باید به آن برسد. اگر ممکن است آن را فقط برای آی‌پی خارج باز کنید:

  ```bash
  sudo ufw allow from IP_خارج to any port 7001 proto tcp
  ```

  وقتی ufw فعال است اسکریپت پورت تانل را برای همه باز می‌کند؛ بعد از آن قانون عمومی را پاک کنید: `sudo ufw delete allow 7001/tcp`.
* **fail2ban روی سرور خارج:** پنل‌هایی مثل 3x-ui ممکن است آی‌پیِ دارای اتصال‌های زیاد را بن کنند. سرور ایران از دید آن‌ها یک آی‌پی است که *همه‌ی کاربران* را حمل می‌کند و ممکن است بن شود؛ آن‌وقت کل تانل کند یا قطع می‌شود. سفیدلیستش کنید:

  ```bash
  sudo ./bpt.sh ignore-ip IP_ایران
  ```
* پورت‌های فوروارد عمومی‌اند: هرچه پشت آن‌ها گوش بدهد در اینترنت دیده می‌شود. پنل‌های مدیریتی را با رمز قوی نگه دارید یا فقط محلی کنید (`127.0.0.1:8080=8080`).

## فایل‌ها و سرویس‌ها

| مسیر | کاربرد |
|---|---|
| `/usr/local/bin/backpack` | باینری BackPack |
| `/etc/backpack/NAME.toml` | تنظیمات تانل (نام پیش‌فرض `bpt`)، دسترسی 600 |
| `/etc/systemd/system/backpack-NAME.service` | سرویس systemd (اجرای خودکار و ری‌استارت هنگام خطا) |
| `/etc/sysctl.d/99-bpt-tune.conf` | با `tune` نوشته می‌شود |
| `/etc/fail2ban/jail.d/bpt-ignore.local` | با `ignore-ip` نوشته می‌شود |

دستورهای مفید خام: `systemctl status backpack-bpt` و `journalctl -u backpack-bpt -f`.

نمونه‌ی تنظیمات در پوشه‌ی [`examples/`](../examples) است.

این راه‌اندازی از ترنسپورت ساده‌ی `tcp` استفاده می‌کند که ساده‌ترین و سریع‌ترین است. BackPack ترنسپورت‌های دیگری هم دارد (مثلاً WSS و PCK)، به‌علاوه‌ی failover و تقسیم بار، تانل مستقیم لایه ۳، پنل وب و پایش با تلگرام. برای آن‌ها `sudo backpack` (CLI خود موتور) را اجرا کنید یا [مستندات اصلی](https://github.com/AminMGMT/BackPack/tree/main/docs) را ببینید. تانل‌های ساخته‌شده با این اسکریپت را می‌توان دستی هم ویرایش کرد: فایل TOML را عوض کنید و `sudo systemctl restart backpack-NAME` بزنید.

## به‌روزرسانی و حذف

```bash
sudo ./bpt.sh update                      # جدیدترین BackPack؛ همه‌ی تانل‌های ساخته‌شده با این اسکریپت ری‌استارت می‌شوند
BP_VERSION=v1.8.5 sudo -E ./bpt.sh update # یک نسخه‌ی مشخص

sudo ./bpt.sh uninstall                   # حذف تانل "bpt"
sudo ./bpt.sh --name web uninstall --purge-binary   # باینری را هم پاک کن
```
