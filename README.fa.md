# BackPack Easy Tunnel — تانل ساده ایران ⇄ خارج

[English](README.md) · **فارسی**

یک اسکریپت Bash که با موتور متن‌باز [BackPack](https://github.com/AminMGMT/BackPack) یک **تانل TCP معکوس بین سرور ایران و سرور خارج** می‌سازد و مدیریت می‌کند.

- **منوی تعاملی** (فارسی / English) و **خط فرمان** برای اسکریپت‌نویسی.
- تغییر **پورت‌های فوروارد**، **آی‌پی ایران** و **پورت تانل** در هر زمان، فقط با یک دستور.
- دانلود نسخه‌ی رسمی BackPack و **بررسی SHA-256** قبل از نصب.
- ساخت تنظیمات و **سرویس systemd** (اجرای خودکار بعد از ری‌استارت)، باز کردن **فایروال** (ufw / firewalld)، **بهینه‌سازی سرعت BBR** و **سفیدلیست fail2ban** (اختیاری).
- چند تانل روی یک سرور (`--name`)، **نصب آفلاین** برای سرورهایی که به GitHub دسترسی ندارند، و `--dry-run` برای دیدن همه‌چیز بدون اعمال تغییر.

> این پروژه فقط نصب‌کننده و مدیر است. موتور تانل، BackPack اثر AminMGMT است (AGPL-3.0) و در این مخزن قرار ندارد و توزیع هم نمی‌شود.

## ساز و کار

```text
                 کاربران
                    │
                    ▼
          ┌───────────────────┐
          │   سرور ایران      │   «ورودی» — کاربران به این وصل می‌شوند
          │ پورت‌های فوروارد   │   مثلاً 80, 443, 2053 ...
          │ پورت تانل 7001    │◀──────────────┐
          └───────────────────┘               │  سرور خارج به این «وصل می‌شود»
                    ▲                         │  (اتصال خروجی؛ نیازی به پورت باز روی سرور خارج نیست)
                    │ ترافیک از داخل تانل رد می‌شود
                    ▼                         │
          ┌───────────────────┐               │
          │   سرور خارج       │───────────────┘
          │ سرویس اصلی        │   «خروجی» — x-ui / Xray / سایت / هر چیز دیگر
          └───────────────────┘
```

* **سرور خارج** اتصال را **به ایران** باز می‌کند (تانل معکوس) و به پورت ورودی احتیاج ندارد.
* **سرور ایران** روی **پورت تانل** (پیش‌فرض `7001`) و همه‌ی **پورت‌های فوروارد** گوش می‌دهد و ترافیک آن‌ها را به سرور خارج می‌رساند.
* دو طرف یک **توکن** مشترک دارند (۶۴ نویسه‌ی هگز که خودکار ساخته می‌شود).

## پیش‌نیازها

| | |
|---|---|
| سیستم‌عامل | لینوکس با **systemd** (Ubuntu / Debian / CentOS / Rocky …) |
| دسترسی | `root` (یا `sudo`) روی هر دو سرور |
| پردازنده | x86_64، arm64، armv5/6/7، 386، s390x |
| شبکه | سرور ایران: پورت تانل و پورت‌های فوروارد از بیرون در دسترس باشند. سرور خارج: دسترسی خروجی به پورت تانل ایران |
| ابزار | `bash`، `curl` یا `wget`، `tar`، `sha256sum` (همه استاندارد) |

## شروع سریع

### ۱) اسکریپت را روی **هر دو** سرور بگذارید

```bash
curl -fsSLo bpt.sh https://raw.githubusercontent.com/yhsoft4/backpack-easy-tunnel/main/bpt.sh
chmod +x bpt.sh
```

> سرورهای ایران معمولاً به GitHub دسترسی ندارند. فایل را روی کامپیوتر خودتان دانلود کنید و با `scp bpt.sh root@IP_ایران:~/` بفرستید. [نصب آفلاین](docs/guide.fa.md#نصب-آفلاین) را ببینید.

### ۲) سرور ایران (ورودی) — اول این را بزنید

تعاملی:

```bash
sudo ./bpt.sh
# زبان را انتخاب کنید، بعد  ۱) راه‌اندازی سرور ایران
```

یا با یک دستور:

```bash
sudo ./bpt.sh install iran --port 7001 --ports "80,443,2053=127.0.0.1:2096"
```

در پایان، یک دستور آماده برای سرور خارج (همراه توکن ساخته‌شده) چاپ می‌شود.

### ۳) سرور خارج (خروجی)

دستوری را که در مرحله‌ی ۲ چاپ شد اجرا کنید:

```bash
sudo ./bpt.sh install kharej --server IP_ایران:7001 --token <توکن_مرحله_۲>
```

### ۴) بررسی

```bash
sudo ./bpt.sh status
```

در لاگ باید `control channel established` ببینید. با اتصال به `IP_ایران:<یکی از پورت‌های فوروارد>` آزمایش کنید.

## نوشتن پورت‌ها (`--ports`)

فهرستی که با کاما جدا شده. سمت چپ: پورتی که **سرور ایران** روی آن گوش می‌دهد. سمت راست: مقصدی که **سرور خارج** ترافیک را به آن می‌فرستد (از دید سرور خارج).

| نوشته | معنی |
|---|---|
| `443` | ایران `:443` ← خارج `127.0.0.1:443` |
| `443=2096` | ایران `:443` ← خارج `127.0.0.1:2096` |
| `443=127.0.0.1:2096` | همان، کامل نوشته‌شده |
| `443=10.0.0.5:8443` | ایران `:443` ← سرور دیگری که سرور خارج به آن دسترسی دارد |
| `10000-10009` | یک بازه، هر پورت به همان پورت |
| `10000-10009=20000-20009` | یک بازه با جابه‌جایی |
| `443=10.0.0.1:80\|10.0.0.2:80` | دو مقصد، با سنجش سلامت و تقسیم بار |
| `127.0.0.1:8080=8080` | فقط روی خود سرور گوش بده |

> **پورت تنها یعنی «هر پورتی» نیست.** `443` یعنی باید روی سرور خارج چیزی روی `127.0.0.1:443` گوش بدهد. اگر پنل شما آنجا روی `2096` است بنویسید `443=127.0.0.1:2096`.

توضیح کامل نحو در مستندات BackPack: [port-mappings](https://github.com/AminMGMT/BackPack/blob/main/docs/port-mappings.md).

## تغییرات بعدی

| می‌خواهم… | کجا | دستور |
|---|---|---|
| پورت‌های فوروارد را عوض کنم | ایران | `sudo ./bpt.sh ports --set "80,443=127.0.0.1:2096"` |
| پورت‌های فعلی را ببینم | ایران | `sudo ./bpt.sh ports` |
| سرور ایران **آی‌پی جدید** گرفت | خارج | `sudo ./bpt.sh set-server IP_جدید[:PORT]` |
| پورت تانل را عوض کنم | هر دو | روی ایران `install iran --force --port N --token <همان توکن>` و روی خارج `set-server IP_ایران:N` |
| توکن را عوض کنم | هر دو | `install … --force --token توکن_جدید` روی هر دو |

> پیشنهاد: برای سرور ایران از **دامنه** استفاده کنید (`--server your.domain.example:7001`). وقتی آی‌پی عوض شد فقط رکورد DNS را تغییر می‌دهید. سمت خارج در هر اتصال دوباره نام را وصل می‌کند؛ اگر بعد از TTL هنوز آی‌پی جدید را نگرفت، همان‌جا `sudo ./bpt.sh restart` بزنید.

## همه‌ی دستورها

```text
./bpt.sh [--name نام] [--lang en|fa] [--yes] [--force] [--dry-run] <دستور>

(بدون دستور)               منوی تعاملی
install iran               سمت ورودی:  --port --bind --ports --token --udp --transport
install kharej             سمت خروجی:  --server --token --pool
status | start | stop | restart | logs
ports [--set "فهرست"]      نمایش / تغییر پورت‌های فوروارد (ایران)
set-server IP[:PORT]       تغییر آدرس ایران (سرور خارج)
show [--reveal]            نمایش تنظیمات (توکن بدون --reveal پنهان است)
list                       تانل‌های ساخته‌شده با این اسکریپت
tune                       BBR + بافر TCP بزرگ‌تر (روی هر دو سرور)
ignore-ip IP               fail2ban: هیچ‌وقت طرف مقابل تانل را بن نکن
update                     به‌روزرسانی BackPack و ری‌استارت تانل‌ها
uninstall [--purge-binary] حذف این تانل
```

متغیرهای محیطی: `BPT_TARBALL` و `BPT_BINARY` (آفلاین)، `BP_VERSION` (نسخه‌ی مشخص مثل `v1.8.5`)، `BP_BASE_URL` (آینه)، `BPT_SKIP_VERIFY=1` (توصیه نمی‌شود)، `BPT_LANG`.

برای دیدن نتیجه بدون تغییر: `--dry-run` را اضافه کنید (و `BPT_ROOT=/tmp/test` در یک پوشه‌ی آزمایشی می‌نویسد).

## نکات و سلب مسئولیت

- فقط روی سرورهایی استفاده کنید که مالک آن‌ها هستید یا اجازه‌ی مدیریتشان را دارید و قوانین کشور خودتان را رعایت کنید. نویسندگان هیچ مسئولیتی در قبال سوءاستفاده ندارند.
- **توکن** را محرمانه نگه دارید: هر کس توکن را داشته باشد و به پورت تانل دسترسی داشته باشد می‌تواند به تانل شما وصل شود.
- آزمایش‌شده: Ubuntu و x86_64 — نصب، بررسی checksum، ساخت تنظیمات و دستورهای مدیریتی (در یک root آزمایشی)، و همین تنظیمات روی یک تانل زنده بین یک سرور Hetzner (آلمان) و یک VPS ایرانی.
